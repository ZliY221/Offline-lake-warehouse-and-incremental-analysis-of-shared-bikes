# 需求与验收标准

## 目标

构建一个可以在个人电脑和 CI 中复现的 PySpark 离线湖仓，使用合成共享单车数据演示批次摄取、分层建模、维度历史、增量处理、数据质量和 SQL 分析。

## 数据集

### 行程事件

粒度：一行代表一次完整行程。

字段：行程 ID、开始/结束时间、起终站点、骑行者类型、车辆类型、距离。不得包含姓名、电话、证件、支付标识或精确轨迹。

### 站点快照

粒度：一行代表某个快照日期上的一个站点状态。

字段：快照日期、站点 ID、名称、行政区、容量和启用状态。后续使用每日快照构建 SCD2。

## 分层要求

- Bronze：显式 Schema 读取，保存来源文件、摄取日期和原始字段，按摄取日期分区。
- Silver：校验业务规则，隔离拒绝记录，按 `trip_id` 去重，派生骑行分钟数和业务日期。
- DIM：根据站点快照维护有效开始、有效结束和当前标记。
- Gold：按日期、行政区、骑行者类型和车辆类型统计行程数、总时长、平均时长和热门路线。

## 增量要求

- 同一摄取日期重跑不得重复追加数据。
- 更新某一日期分区不得删除其他日期分区。
- 输入清单应记录批次、文件哈希、行数和状态。
- 回填历史日期时必须明确影响的分区和指标。

## 验收标准

1. 相同生成参数得到完全相同的输入文件。
2. Spark 使用显式字段类型，不依赖生产输入的自动推断。
3. Bronze Parquet 按 `ingestion_date` 分区。
4. 同日重跑行数不翻倍，另一日期分区保持不变。
5. Silver 能区分合法、重复和至少五类业务失败。
6. 站点属性变化产生不重叠的 SCD2 有效期。
7. Gold 指标可由小样本手工核对。
8. 所有性能数字具有环境、输入、方法和原始逐轮结果。

当前仅完成第 1—4 项；其余项目继续按阶段实现。
